# Wink 0.6.0 — Portable web apps (experimental)

- New Apps menu opens HTML/CSS/JavaScript plugins in dedicated, isolated windows.
- Portable API 1 package manifest and `blink` JavaScript API, designed for a future Blink host.
- Host capability information and permission-gated, persistent per-plugin storage.
- Bundled Plugin Playground demonstrates the native bridge and saved notes.
- Local package discovery from the Apps folder; no registry or downloads required.
- Package path validation, storage quotas and a restrictive offline content policy.

Choose **Apps → Plugin Playground** to try it, or **Apps → Open Apps Folder…**
to add a trusted local package. See `docs/plugins.md` in the repository for the
package format and API.

This is an experimental, local-only extension foundation. Blink/iOS support,
Spotify/Apple Music playback, network access and a plugin marketplace are not
included. Existing terminal behavior is unchanged.

Universal macOS build for Apple Silicon and Intel; macOS 13 or later.
