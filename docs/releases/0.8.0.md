# Wink 0.8.0

- Spotify: experimental **Play in Wink** streams through Spotify’s Web Playback SDK without requiring a separate Spotify app. Premium required. Existing users must disconnect/reconnect once to grant streaming permission.
- Spotify’s streaming SDK receives short-lived access tokens; refresh tokens remain in macOS Keychain. Other plugins remain offline and cannot access this bridge.
- Includes plugin tabs, GitHub app installation, Spotify OAuth, and the corrected GitHub repository lookup from the unreleased 0.7.0 work.

## Verification and limitations

Universal macOS build and plugin/package/installer/OAuth/WebView checks pass. Real WKWebView FairPlay capability and the Spotify SDK iframe handshake pass. Live account authorization, DRM license acquisition and audible playback are **not yet verified**; in-app streaming remains experimental. Spotify development-mode account limits still apply.

The plugin source is available at https://github.com/myneid/wink-spotify. It ships with Wink and requires Wink’s privileged native Spotify bridge; installing the repository over the bundled plugin is neither necessary nor supported.
