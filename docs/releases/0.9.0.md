# Wink 0.9.0

- Spotify: artist search → discography → album tracks → full-album playback, with release filters, pagination and back navigation.
- Apps → Manage Apps opens a keyboard-driven terminal-style tab: launch, install from GitHub, check for updates and apply reviewed updates.
- GitHub updates stay bound to the installed repository/path/ref, preserve app identity and storage, and retain the previous package as a backup. No silent installation.
- Bundled plugins, including Spotify, update with Wink.
- Portable HTML/CSS/JavaScript manager and blink.apps host contract; Blink/iOS host implementation is not included.
- Live Spotify account browsing/audio remains unverified. Streaming requires Premium and access to Wink’s development-mode Spotify integration.
